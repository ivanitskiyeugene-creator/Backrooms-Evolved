# Backrooms Evolved

Мод для **Minecraft 1.20.1 (Forge 47)** — набор блоков и механик, чтобы построить
свой уровень 0 Бекрумса прямо в игре. Бекрумс **не генерируется сам**: ты строишь
его из блоков, а мод добавляет атмосферу — гул ламп, эхо, сырость, безумие и камеру.

## Что внутри

### Блоки
| Блок | Фишки |
|---|---|
| Влажный ковёр | вязнет в шагах; рядом сыреет воздух (туман, «запотевание», глухой гул подвала) |
| Старый ковёр | остаются вмятины от шагов, медленно расправляются; следы «чужих» можно поставить руками |
| Ковёр с пятнами | влажные тёмные пятна. ты не знаешь, что это |
| Флуоресцентная / белая лампа | гудит, иногда мигает (в мигание можно «подсмотреть» фигуру), изредка **перегорает навсегда**; чинится пыльцой светокамня |
| Красная аварийная лампа | тревожно пульсирует. красный — значит что-то не так |
| Стеновая панель, старые обои | для стен уровня 0 |
| Якорь рассудка | тёплый свет, рядом восстанавливается рассудок |

### Камера Бекрумса
- **ПКМ** — переключение режимов: обычный / **ИК** (ночное видение, зелёный тон;
  в ИК иногда видно то, чего не видно глазом).
- **ПКМ + Shift** — открыть экранчик и **отмотать запись** назад (слайдер, ▶, стрелки, пробел).
- **R** — начать/остановить запись (кадры пишутся в `<.minecraft>/backrooms_recordings/<id>/`).
- Батарея тратится (в ИК и при записи — быстрее), села — останешься в темноте.
  Зарядка: камера + батарея в верстаке.
- Рядом с монстрами камера **глючит**: полосы, треск, помехи.

### Рассудок (санити)
- Растёт среди блоков Бекрумса и в темноте, сбрасывается у якоря или вне Бекрумса.
- Шкала в правом верхнем углу HUD.
- >50 — шёпот из ниоткуда; >70 — сердцебиение, силуэты фигур, завал камеры;
  >85 — глитчи и подвальный гул.

### Атмосфера
- **Эхо**: шаги и звуки блоков отражаются с задержкой — в маленькой комнате короткое,
  в огромном зале длинное и гулкое (объём комнаты измеряется на лету).
- **Гул ламп** рядом с горящими лампами; **подвальный гул** при сырости/безумии.
- **Сырость**: туман сгущается и «запотевает» экран рядом с влажным ковром.

## Сборка

Нужны: **JDK 17**, доступ в интернет (Maven Central / Forge maven).
Gradle wrapper уже в репозитории, поэтому просто:

```bash
./gradlew build
```

Готовый jar лежит в `build/libs/backroomsevolved-1.0.0.jar` — кидай в `mods/`.
Запуск из IDE: `./gradlew runClient`.

### Готовая сборка (без локального Gradle)
GitHub Actions собирают мод при каждом пуше и выкладывают jar в
**Releases → v1.0.0** (ассет `backroomsevolved-1.0.0.jar`). Скачал — кинул в `mods/` — играешь.

## Регенерация ассетов
Текстуры и звуки сгенерированы процедурно и воспроизводимо:
```bash
pip install numpy pillow soundfile
python3 scripts/gen_textures.py
python3 scripts/gen_sounds.py
python3 scripts/gen_json.py   # blockstates/models/recipes
```

## Управление
| Клавиша | Действие |
|---|---|
| ПКМ (камера) | режим обычный/ИК |
| ПКМ + Shift (камера) | просмотр записи |
| R (камера в руке) | запись вкл/выкл |

## Крафты
- Камера: железо/стекло/репитер; батарея: железо + редстоун-блок.
- Лампа: стекло + железо + пыль светокамня; белая/красная — перекраска.
- Якорь рассудка: железо + эндер-жемчуг + светокамень.
- Ковры — из шерсти/красителей.
